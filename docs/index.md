# SDR-Hub Documentation

Welcome to the SDR-Hub documentation.

## Overview

SDR-Hub is a Software Defined Radio service for Home Assistant OS (HAOS) and standalone Docker environments. It provides USB device passthrough, a web UI via Ingress, and MQTT telemetry.
