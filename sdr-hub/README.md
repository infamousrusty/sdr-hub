# SDR-Hub Home Assistant Add-on

Software Defined Radio hub with USB passthrough, Ingress UI and MQTT integration for Home Assistant.

## Features

- USB SDR device passthrough
- Web UI via Home Assistant Ingress
- MQTT integration for automations
- Multi-arch support (aarch64, amd64)

## Installation

Add this repository to your Home Assistant OS instance, then install the SDR-Hub add-on from the store.

## Configuration

- `log_level`: debug, info, warning, error
- `mqtt_host`: optional MQTT broker hostname (defaults to core-mosquitto)
